## Características

* **Desarrollo:** Hecho con **Astro** para buen rendimiento y entrega de HTML estático sin sobrecarga de JavaScript.
* **Modo Claro / Oscuro:** Sistema de temas dinámico mediante variables CSS y preferencia guardada en `localStorage`.
* **Diseño 100% Responsivo:** Adaptado sin problemas desde pantallas móviles pequeñas hasta monitores UltraWide.
* **Formulario de Contacto Activo:** Integración sin backend con **FormSubmit** y canal de contacto rápido mediante enlace directo a **WhatsApp**.
* **Componentes Modulares e Aislados:** Estilos scoped e integración fluida de utilidades globales.

---

## Tecnologías Utilizadas

* **Framework:** [Astro](https://astro.build/)
* **Estilos:** CSS3 nativo (Custom Properties / Flexbox / Grid)
* **Iconos:** FontAwesome / Devicon
* **Integración de Formulario:** [FormSubmit](https://formsubmit.co/)

## Instalación Local

Si quieres clonar este proyecto y ejecutarlo en tu entorno local, sigue estos pasos:

1. Clona el repositorio:

```bash
git clone https://github.com/tu-usuario/tu-repositorio.git
```
2. Entra al directorio del proyecto:
```bash
cd tu-repositorio
```
3. Instala las dependencias:
```bash
npm install
```
o
```bash
pnpm install
```
4. Inicia el servidor de desarrollo:
```bash
npm run dev
```
5. Abre tu navegador e ingresa a http://localhost:4321.
